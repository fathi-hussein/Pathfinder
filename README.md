# Pathfinder

Pathfinder is a personal learning and career discovery platform designed to help individuals navigate the world of technology careers.

It aims to replace confusing advice with honest guidance, structured career information, and practical learning resources.

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
